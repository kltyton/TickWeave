# TickWeave 2.1.17+hotfix.2

## 中文

将 Mixin 生成类的实际布局纳入状态分析缓存，使运行时内类无需磁盘 class 资源即可完成方法标记和字段布局检查。保留 native 状态保护、固定引用优化，以及实体、玩家和区块并行。

## English

Retains the live layouts of Mixin-generated classes for state analysis, allowing runtime inner classes to expose method flags and field layouts without a disk class resource. Native-state protection, fixed-reference optimization, and parallel entity, player and chunk work remain in place.
