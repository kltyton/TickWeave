# TickWeave 2.1.17+hotfix.5

## 中文

- 新增了对 Cardinal Components Entity 属性容器的兼容性：该容器会在运行时为所有实体附加一个数据容器。此数据容器是动态生成的，通常为空，除非 Fabric 模组通过相应的桥接为实体附加属性。虽然这可能不是修复该问题的最理想方式，但它确实有效。
- 将 Level 中的 RandomSource 替换为线程安全包装器，以兼容 C2ME 及其他模组。
- 添加了俄语（RU）翻译。

## English

- Compatibility has been added with the Cardinal Components Entity attribute container, which attaches a data container to all entities at runtime. This data container is generated on the fly and is typically empty, unless Fabric mods attach attributes to entities via the appropriate bridges. While perhaps not the most ideal way to fix the issue, it is an effective one.
- Replacing RandomSource in Level with a thread-safe wrapper for compatibility with C2ME and other mods.
- Added RU translation.

## Russian

- Добавлена совместимость с контейнером атрибутов Cardinal Components Entity, который во время выполнения прикрепляет контейнер данных ко всем сущностям. Этот контейнер данных создаётся на лету и обычно пуст, если только Fabric-моды не прикрепляют атрибуты к сущностям через соответствующие мосты. Хотя, возможно, это не самый идеальный способ исправить проблему, он эффективен.
- Замена RandomSource в Level на потокобезопасную обёртку для совместимости с C2ME и другими модами.
- Добавлен RU перевод.
