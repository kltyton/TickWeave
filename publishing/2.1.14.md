# TickWeave 2.1.14

## English

- Forge: damage rejected by the target's native `isInvulnerableTo` check no longer fires `LivingAttackEvent`. Attack listeners and scripts will not see those rejected attacks; ordinary vulnerable targets still fire the event.
- Forge/Fabric: prevent a dedicated-server crash when an entity has a field whose client-only type is unavailable. Other entity fields remain in shared-state ownership checks.
- Forge: coordinate Forge's merged spawn-placement callbacks that may use shared mutable state. Chunk spawning jobs remain parallel; this addresses the Terra Entity 1.2.3 NPC spawner crash.
- Coordinate player chunk tickets and fake-player embedded-channel sends across worker threads.
- Keep unrelated external blocking commands in the server queue until the current entity batch finishes, so save commands do not enter the cooperative entity callback pump.

For Minecraft 1.20.1 and Java 17. Choose the Forge or Fabric file for your loader. Performance and compatibility depend on the modpack and world; test on a copy before updating a server.

## 简体中文

- Forge：目标原生 `isInvulnerableTo` 已判定无效的攻击不再触发 `LivingAttackEvent`。这类攻击不会再进入事件监听器和脚本；普通可受伤目标仍会触发事件。
- Forge/Fabric：实体字段引用服务端不存在的客户端类型时不再直接崩溃，其余字段继续参与共享状态归属检查。
- Forge：协调可能访问共享可变状态的 Forge 合并刷怪谓词回调；各区块刷怪任务仍并行，修复 Terra Entity 1.2.3 NPC 刷怪崩溃。
- 协调玩家区块票据与假玩家嵌入通道发包的跨线程访问。
- 无实体因果关系的外部阻塞命令等当前实体批次结束后再由原生服务器队列执行，避免保存命令进入实体回调协作泵。

适用于 Minecraft 1.20.1、Java 17。按 Loader 选择 Forge 或 Fabric 文件。性能和兼容性取决于整合包与世界状态，更新服务器前请在副本中测试。
