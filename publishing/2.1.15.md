# TickWeave 2.1.15

## 中文

修复共享描述对象导致实体被错误合并到同一执行组的问题。字段引用固定的对象现在按其引用的实际可变状态参与归属分析；空描述对象和标量配置不再仅因对象身份相同而串联实体。嵌套可变对象、NBT别名、实体关系与任务完成屏障仍保留保护，实体、玩家连接和区块工作继续并行。

适用于Minecraft 1.20.1、Java 17的Forge和Fabric。此版本改善服务器Tick调度，不优化FPS。

## English

Fixes entity groups being joined through shared descriptor objects. Objects with fixed field references are now analyzed through the mutable state they reference; empty descriptors and scalar configuration values no longer join entities solely through their identity. Protection for nested mutable state, NBT aliases, entity relationships and batch completion remains in place. Entity ticking, player connections and chunk work remain parallel.

For Minecraft 1.20.1 on Java 17, with Forge and Fabric builds. This change concerns server ticks and does not improve FPS.
