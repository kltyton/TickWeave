# TickWeave 2.1.14+hotfix

## 中文

修复 KubeJS/Rhino 脚本给其他实体添加效果时，脚本锁与实体归属任务互相等待、最终触发服务器看门狗的死锁。脚本执行与作用域操作由服务器线程协调，保留原生脚本互斥、重入、返回值和异常；实体 tick、玩家连接和区块刷怪继续并行。

## English

Fixes a server watchdog deadlock between KubeJS/Rhino's script lock and entity ownership tasks when a script applies effects to another entity. Script execution and scope operations are coordinated on the server thread while retaining native script exclusion, reentry, return values and exceptions. Entity ticking, player connections and chunk spawning remain parallel.
